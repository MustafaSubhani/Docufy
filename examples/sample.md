# 01 Executive Summary

## Proposal Overview

:::columns
### The Challenge
ADICC operates across multiple construction projects in the UAE and currently relies on a combination of market-leading tools and manual processes for estimation, scheduling, contract management, and document access. The absence of a single, integrated platform creates duplication of effort, data silos between departments, and a lack of real-time visibility across projects.

### The Opportunity
By consolidating all four capability areas into a single AI-powered platform purpose-built for the UAE construction context, ADICC can eliminate tool fragmentation, reduce duplication, and unlock a unified operational view across estimation, scheduling, contracts, and knowledge management.
:::

:::callout
### Our Approach
Spark Technologies has reviewed all four capability requirements submitted by ADICC and proposes a single unified platform delivered across all four modules simultaneously. The platform is built from the ground up for the UAE construction context — trained on UAE authority drawing conventions, FIDIC contract standards, GCC schedule risk profiles, and UAE construction law.
:::

:::callout
### The Outcome
ADICC receives a single AI-powered platform covering automated quantity takeoffs from PDF drawings, schedule risk analysis integrated with Primavera P6, clause-level contract intelligence and claims management, and a Telegram-based document access bot connected to ADICC's internal file repository.

# 03 Solution Overview

## Our Assessment

Spark Technologies has reviewed all four capability requirements submitted by ADICC. Our assessment evaluated each requirement against three criteria: technical feasibility, UAE construction context fit, and alignment with ADICC's existing systems and workflows.

### Module 1 — Estimation & Quantity Takeoff

ADICC currently evaluates Togal.AI as a benchmark for AI-powered estimation. Our proposed solution is a custom-built AI Estimation Engine that ingests PDF and CAD drawing sets, automatically detects and classifies building elements by type, and generates itemised quantity takeoffs mapped to ADICC's preferred cost database and UAE trade rates.

### Module 2 — Scheduling & Project Controls

Our proposed solution is a custom AI Schedule Risk platform that connects directly to ADICC's existing Primavera P6 environment via native XER/XML export — no schedule rebuild required. The platform runs automated QSRA using a risk model trained on historical construction schedule data from the UAE and GCC region.

### Module 3 — Contract Management & Claims

The platform reviews new contracts clause by clause against a risk library built from ADICC's historical claims experience, drafts notices and extension of time submissions, calculates financial entitlements, and prepares structured arbitration pleadings with evidence organisation.

### Module 4 — Telegram Document Access Bot

We recommend Telegram as the interface for this module. Telegram's fully open Bot API supports unlimited automated messaging, file delivery, natural language query handling, and role-based access controls with no platform restrictions on automation.

# 04 Scope of Work

## Scope of Work

Spark Technologies proposes delivery of all four platform modules as a single unified engagement. All modules share one platform foundation, one unified dashboard, and one integration path into ADICC's existing systems.

### Module 1 — AI Estimation & Quantity Takeoff Engine

This module delivers an AI-powered estimation layer that ingests PDF drawing sets and automatically generates itemised quantity takeoffs, material schedules, and preliminary cost estimates mapped to UAE trade rates and ADICC's preferred cost database.

**Scope includes:**

- **Drawing ingestion pipeline** — accepts PDF, DWG, and scanned drawing sets in standard UAE authority submission formats
- **AI element detection engine** — identifies and classifies structural, architectural, MEP, and civil elements from drawing sets
- **Automatic quantity calculation** — generates itemised takeoff schedules with units, quantities, and UAE-standard waste factors
- **UAE trade rate database integration** — maps quantities to ADICC's preferred rate schedule and current UAE market rates
- **Drawing version comparison** — detects and quantifies changes between drawing revisions for change order management
- **Team collaboration layer** — multi-user access with role-based permissions, annotation, and approval workflow
- **Export to Excel, PDF, and ADICC's ERP** and estimating system
- **Arabic drawing set support** — element detection trained on Arabic-language annotation and UAE authority drawing conventions

| AI Use Case | Description | Expected Output |
| --- | --- | --- |
| Drawing Element Detection | Deep learning model detects and classifies structural, architectural, MEP, and civil elements directly from PDF drawing pages | Classified element schedule with quantities and dimensions per drawing |
| Quantity Takeoff Generation | AI engine calculates net and gross quantities per element type, applying UAE-standard waste factors and coverage rates | Itemised BOQ-format takeoff schedule exportable to Excel and ERP |
| Cost Estimation | Quantities mapped against ADICC cost database and live UAE trade rates to produce preliminary cost estimates | Preliminary cost plan with line-item breakdown and total project estimate |
| Drawing Version Delta | Comparison engine analyses two drawing revisions and identifies added, removed, and modified elements with quantity impact | Change register with quantity and cost impact per revision |
